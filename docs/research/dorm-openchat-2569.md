# หาหอ: คำถามจริงจาก OpenChat "หอมจธ" (ประมาณ ก.ค.–ต.ค. 2569)

ผู้พัฒนาจดข้อความจาก OpenChat หาหอของนักศึกษา มจธ. ช่วงประมาณ 4 เดือน ได้ราว 200 ข้อความ (ข้อความบางส่วนหายไป เพราะ LINE เก็บย้อนหลังได้แค่ประมาณ 1 เดือน)
**ไฟล์ต้นฉบับไม่ขึ้น git** หน้านี้สรุปเฉพาะประเภทคำถาม ชื่อหอที่ถูกพูดถึง และข้อเท็จจริงที่นักศึกษาเล่า ไม่มีชื่อคนหรือช่องทางติดต่อส่วนตัว
ตัวเลขทุกตัวในหน้านี้ **มาจากโพสต์ของนักศึกษา (tier: student)** ไม่รู้วันที่โพสต์แน่ชัด ยังไม่ได้ยืนยันกับหอ

ข้อสังเกตแรก: กลุ่มนี้เป็น **ตลาดซื้อขายสัญญาและหารูมเมท** มากกว่ากลุ่มถามข้อมูล ประมาณครึ่งหนึ่งของข้อความเป็นการปล่อยหรือหาสัญญาต่อและการหารูมเมท ซึ่งแชทบอทช่วยได้น้อย ส่วนที่เหลือเป็นคำถามว่าหอไหนดี ราคาเท่าไหร่ มีอะไรบ้าง ซึ่งเป็นงานที่ทางมดช่วยได้

### แหล่งข้อมูล เรียงจากคุ้มสุด
1. **OpenChat ที่เก็บมา (ไฟล์นี้):** บอกได้ดีที่สุดว่าคนสนใจหอไหน และได้ราคาหรือรีวิวจริง แต่ไม่ครบและไม่รู้วันที่ → ใช้เลือกว่า **ควรเก็บหอไหนก่อน** (15–20 แห่งในตารางด้านบน)
2. **เว็บประกาศเช่า hongpak.in.th / renthub.in.th / DDproperty:** มีช่วงราคา ค่าน้ำไฟ ระยะ และบางทีมีวันที่อัปเดต → เปิดดูรายหอแล้วจดพร้อมลิงก์ (แบบที่ทำใน [dorm-outside.md](dorm-outside.md)) **ไม่แนะนำให้เขียนสคริปต์ดูดข้อมูล** เพราะเว็บเหล่านี้ไม่มี API สาธารณะ และการ scrape อาจผิดเงื่อนไขการใช้งาน
3. **เพจ Facebook / LINE OA ของหอ:** ราคาล่าสุด สัญญาสั้น สัตว์เลี้ยง → ทักถามตรงได้ (เหมาะกับหอที่ถูกพูดถึงบ่อย)
4. **ถามในกลุ่มเอง:** ตั้งคำถามรอบเดียว เช่น "หอไหนสัญญา 6 เดือน / เลี้ยงแมวได้ / ไฟหลวง" จะได้คำตอบหลายหอพร้อมกัน
5. **Google Maps (ดูด้วยตา):** ยืนยันพิกัด ระยะเดิน และอ่านรีวิว

### ถ้าจะใช้ API ดึงข้อมูลจากภายนอก
| API | ได้อะไร | ข้อจำกัด |
|---|---|---|
| **Google Places API** (Text Search / Nearby Search รอบพิกัด มจธ.) | ชื่อ ที่อยู่ พิกัด เบอร์ที่ร้านลงไว้ คะแนนและรีวิว | ต้องผูกบัตรเครดิตกับ Google Cloud (มีเครดิตฟรีรายเดือน ให้เช็กราคาปัจจุบันก่อนใช้) · **เงื่อนไขห้ามเก็บข้อมูลไว้ถาวร** (ยกเว้น place_id) จึงเอามาใส่ KB ตรง ๆ ไม่ได้ ใช้ได้แค่ช่วยหาและยืนยันพิกัด · ไม่มีราคาห้อง |
| **Longdo Map API** (แผนที่ไทย) | ค้นสถานที่ภาษาไทย พิกัด | ข้อมูลหอเล็ก ๆ อาจไม่ครบ ต้องสมัคร key · ไม่มีราคาห้อง |
| **OpenStreetMap (Overpass API)** | ฟรี ไม่ต้องใช้ key ค้นตึกที่ติดแท็กหอพักรอบ ๆ ได้ | ข้อมูลหอในไทยน่าจะมีน้อย ต้องให้เครดิต (ODbL) · ไม่มีราคา |

**คำแนะนำ:** API ช่วยได้แค่ **ชื่อ พิกัด และระยะ** แต่สิ่งที่นักศึกษาถามจริงคือราคา ค่าไฟ สัญญา สัตว์เลี้ยง และรีวิว ซึ่งไม่มี API ไหนให้ ถ้าใช้ API แบบดึงสด (เรียกทุกครั้งที่มีคนถาม) ต้องแก้ `lib/ai/retrieve.ts` และเพิ่ม key ซึ่งเป็นงานใหญ่และเสียค่าใช้จ่าย จึง **แนะนำให้ทำตารางด้วยมือก่อน 15–20 หอ** แล้วแปลงเป็น KB ซึ่งครอบคลุมคำถามส่วนใหญ่ได้เร็วกว่า
